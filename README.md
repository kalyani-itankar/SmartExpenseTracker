# 💰 Smart Expense Tracker

A simple personal finance web application built with **Python, Streamlit, SQLite, Pandas, and Matplotlib**.

## 🚀 Features

* 💰 Add and track income
* 💸 Add daily expenses
* 🎯 Set a monthly budget
* 📊 View spending analytics
* 📅 Analyze expenses by month or date range
* 🏷️ Category-wise spending analysis
* 📈 Daily spending trends
* 🧠 Smart spending insights
* ✏️ Edit expenses
* 🗑️ Delete expenses
* 📥 Export expenses to CSV

## 🛠️ Technologies Used

* Python
* Streamlit
* SQLite
* Pandas
* Matplotlib

## 📂 Project Structure

```text
SmartExpenseTracker/

```

## ▶️ How to Run

Install the required libraries:

```bash
pip install streamlit pandas matplotlib
```

Then run:

```bash
streamlit run streamlit_app.py
```

The application will open in your browser.

## 🎯 Purpose

The goal of this project is to make personal expense tracking simple and provide useful visual insights into spending habits.
